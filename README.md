# Radical Engineering – eCommerce Platform

Radical Engineering is a full-featured eCommerce platform built with modern web technologies including Next.js 14+, Directus CMS, Redux, Tailwind CSS, and server-side rendering for performance and SEO. It supports secure product management, customer-friendly UI, wishlist, cart, and a Solar System Builder tool.

---

## 🚀 Features

- ⚙️ **Built with Next.js 14 (App Router)**
- 🎨 **Tailwind CSS for styling**
- 🛍️ **Dynamic product management via Directus**
- 🛒 **Cart & Wishlist with Redux**
- 🌞 **Solar System Builder (Smart Calculator)**
- 💬 **Featurable Review Carousel using Keen Slider**
- 🔒 **Secure API proxying to protect external keys**
- 📱 **Fully responsive and optimized for mobile (Capacitor App supported)**
- 🌙 **Dark/Light theme toggle**
- 🔔 **Mobile push notification support (FCM ready)**

---

## 📦 Tech Stack

| Layer      | Technology                         |
| ---------- | ---------------------------------- |
| Frontend   | Next.js 14, Tailwind CSS           |
| State Mgmt | Redux Toolkit                      |
| CMS        | Directus (hosted via Nginx on VPS) |
| Image Zoom | `react-medium-image-zoom`          |
| PDF Viewer | Google Docs Viewer                 |
| Slider     | Keen Slider                        |
| Deployment | VPS (Nginx, Certbot SSL)           |
